# PaperArxiv v0.2.0

## What's New

- **AI Integration**: Automatic paper metadata extraction with Ollama
- **Modern Stack**: Upgraded to Electron 33 + Vue 3 + Element Plus  
- **Apple Silicon**: Native support for M1/M2/M3 Macs
- **Bug Fixes**: Fixed search, author matching, and build issues

## Downloads

- **macOS Universal**: PaperArxiv-0.2.0-universal.dmg (Intel + Apple Silicon)
- **macOS ARM64**: PaperArxiv-0.2.0-arm64.dmg (Apple Silicon only)
- **macOS Intel**: PaperArxiv-0.2.0.dmg (Intel only)

## Requirements

- macOS 10.12+
- Poppler: `brew install poppler`
- Ollama (optional): https://ollama.com
